openMarquee — ffmpeg.wasm spike

This is the Phase 1 spike page — a live exercise of the two content pipelines from IMPLEMENTATION_PLAN.md §Phase 1: H.264 MP4 re-encode (for HDMI renderers) and raw RGB frame extraction (for HUB75 / WS2812B / composite panels).

Pick a source video, choose a pipeline, and the browser decodes + scales + processes it via ffmpeg.wasm entirely client-side. The produced artifact downloads as a file so you can byte-compare against an ffmpeg CLI reference.
